# Supabase Setup Guide — ModaMind

## 1. Create a Supabase project

1. Go to [supabase.com](https://supabase.com) and sign in.
2. Click **New Project**.
3. Pick an organization, enter a project name (e.g. `modamind`), set a database password, and choose a region close to you.
4. Wait for provisioning to finish (~1 minute).

## 2. Get your API keys

1. In the Supabase dashboard go to **Settings → API**.
2. Copy **Project URL** and **anon / public** key.

## 3. Paste them into your `.env.local`

Open `.env.local` at the project root and fill in:

```
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key-here
```

> These are already configured if you see values in `.env.local`.

## 4. Run the SQL migration

1. In the Supabase dashboard go to **SQL Editor**.
2. Click **New query**.
3. Open the file `supabase/migrations/001_initial_schema.sql` from this project.
4. Copy-paste the entire contents into the editor and click **Run**.

This creates all 5 tables, indexes, and Row Level Security policies.

## 5. Create a test user

For development you need at least one authenticated user:

1. Go to **Authentication → Users** in the Supabase dashboard.
2. Click **Add user → Create new user**.
3. Enter an email and password (e.g. `demo@modamind.test` / `demo1234`).
4. Use these credentials to sign in when the login flow is implemented.

## 6. (Optional) Create the storage bucket

If you plan to upload product images later:

1. Go to **Storage** in the dashboard.
2. Click **New bucket**, name it `product-images`, and check **Public bucket**.
3. Or uncomment and run the storage section at the bottom of the migration SQL.

## Schema overview

```
products  ←──  product_attributes   (1 : many)
    ↑
    └── outfit_items  ──→  outfits  ←──  outfit_content
```

- `products` and `outfits` have an `owner_id` column (defaults to the logged-in user via `auth.uid()`).
- Child tables inherit access control via foreign-key joins in RLS policies.
- All primary keys are UUIDs auto-generated by `gen_random_uuid()`.
